# Mail Server Setup Suite

This workspace contains two workspaces that collaborate to give you a fast, Vercel-style feel for launching a mail server.

## Structure

- `backend/` – Express service that builds DNS records, DKIM keys, and the docker-mailserver template.
- `frontend/` – React + Vite dashboard that lets you input domain info and copies the backend data into a polished UI.

## Getting started

1. Install dependencies from the repo root. The workspace is configured as:
   ```bash
   npm install
   npm install --workspaces
   ```
2. Start the backend in one terminal:
   ```bash
   cd backend
   npm install
   npm run dev
   ```
3. In another terminal, start the dashboard:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
4. Visit http://localhost:5173, enter your domain, and copy DNS + Docker instructions.

## Deployment guidance

- The backend already ships with `docker-compose.yml`, `mailserver.env`, and instructions to mount the `config` directory for DKIM keys.
- Use `docker compose up -d` from `backend/` when you are ready to launch the stack; update `mailserver.env` and the DKIM private key generated by `/api/setup`.
- For TLS, mount your certificates under `config/` and keep the DKIM key private.
